# Kiểm tra chế độ thi đấu

Chỉ tick sau khi thực hiện trên phần cứng thi đấu. Dữ liệu giả lập không thay nghiệm thu. Giá trị chưa có thuật toán/mô hình phải hiển thị là chưa có.

- [ ] Ngắt Internet.
- [ ] Ngắt USB khỏi ESP32.
- [ ] ESP32 dùng pin đã kiểm chứng.
- [ ] Wi-Fi cục bộ hoạt động.
- [ ] ESP32 kết nối LAN.
- [ ] Laptop cùng LAN.
- [ ] Backend đang chạy.
- [ ] Dashboard đang chạy.
- [ ] Nhận diện thiết bị đang kết nối.
- [ ] Có telemetry mới.
- [ ] Nhịp tim hiển thị đúng khi hợp lệ, null khi chưa có.
- [ ] GSR hiển thị đúng đơn vị/trạng thái.
- [ ] Chuyển động hiển thị đúng khi đã có thuật toán.
- [ ] Chất lượng hoặc nhãn chưa xác định đúng quy ước.
- [ ] Có điểm dự đoán khi đã có mô hình; chưa có thì null.
- [ ] NORMAL đúng theo mô hình đã kiểm chứng.
- [ ] ATTENTION đúng tiêu chí kỹ thuật.
- [ ] UNCERTAIN đúng khi chưa đủ dữ liệu.
- [ ] Thử ngắt Wi-Fi.
- [ ] ESP32 vẫn lấy mẫu.
- [ ] ESP32 vẫn suy luận tại thiết bị.
- [ ] Kết nối lại Wi-Fi.
- [ ] ESP32 tự kết nối lại.
- [ ] Dashboard nhận bản mới, không nhầm dữ liệu cũ là trực tiếp.
- [ ] Không cần khởi động lại ESP32.
- [ ] Không cần USB để truyền dữ liệu.
- [ ] Không cần Internet.
- [ ] Laptop không suy luận thay ESP32.
